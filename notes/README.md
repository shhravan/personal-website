# notes

Short notes for the notebook on shravanlad.com/blog. One file per note:

- **Name:** `YYYY-MM-DD-a-few-words.md`, for example `2026-11-05-first-note.md`
- **First line:** `# a title` (without one, the first words are used)
- **A picture:** `![a caption](/images/blog/photo.jpg)` on its own line
- **Then:** plain paragraphs with a blank line between them
- **Links:** `[words](https://somewhere.com)`, or to your own pages: `[my work](/work/)`
- `*italic*`, `**bold**`

On your phone: GitHub app → this repository → `notes` → **+** → new file → write → commit to `main`.
The note shows up on the site a minute or two later. Delete the file to remove the note.
